例9 · 小球落弹簧（多选） AC
题型：小球接触弹簧的运动过程分析

小球刚接触弹簧时，重力 mg > 弹力 kx，合力向下，加速度向下且与速度同向 → 速度增大；随压缩量 x 增大，弹力增大，加速度 a = (mg − kx)/m 逐渐减小。

当 kx = mg 时（B点），a = 0，速度达到最大。

继续向下，kx > mg，合力向上，加速度向上且逐渐增大，与速度反向 → 速度减小，直到速度为0（C点，压缩最短）。

结论：加速度先减小后增大，速度先增大后减小。 选 AC。

例10 · 等时圆 D
技巧：等时圆结论

设圆的半径为 R，任意一条弦与竖直方向夹角为 θ：

弦长 L = 2R·cosθ
加速度 a = g·cosθ
由 L = ½at² → t = √(2L/a) = √(4R/g)

时间 t 与角度 θ 无关，只与圆的半径 R 和 g 有关。

因此 a、b、c 三点滑到 d 点的时间相等：t₁ = t₂ = t₃。选 D。

例11 · 内力公式（多选） BD
巧解：内力公式 F内 = (m未/m总)·F

三个物块质量 m、2m、3m，总质量 6m。

R、Q 之间的作用力 F_RQ（只推 R）：

F_RQ = (m_R / m总)·F = (3m / 6m)·F = F/2

Q、P 之间的作用力 F_PQ（推 Q + R）：

F_PQ = ((m_Q + m_R) / m总)·F = (5m / 6m)·F = 5F/6

比值 k = F_RQ / F_PQ = (F/2) / (5F/6) = 3/5

内力公式中摩擦力（μ）在整体和隔离时被同时约掉，k 与 μ 是否为零无关。故选 BD。

例12 · 板块运动 v-t 图像（多选） AD
题型：板块模型共速后判断

地面给整体的滑动摩擦力：μ₂(M+m)g，若一起运动，加速度 a = μ₂g。

物块 m 需要的静摩擦力 f = ma = mμ₂g，最大静摩擦力约为 μ₁mg。

情况一：μ₁ ≥ μ₂ → 所需静摩擦力 ≤ 最大静摩擦力，二者一起减速，v-t 图为同一条直线。对应 A 正确，C 错误。

情况二：μ₁ < μ₂ → 静摩擦力不足，发生相对滑动：

物块 m：a₁ = μ₁g（减速）
木板 M：a_M = [μ₂(M+m)g − μ₁mg] / M > μ₂g > μ₁g

木板减速更快（v-t 图线更陡），先停下，物块后停下。对应 D 正确，B 错误。

例13 · μ = tanθ 结论 C
题型：滑块匀速下滑条件

原来匀速下滑：μmgcosθ = mgsinθ → μ = tanθ。

加竖直向下的力 F 后，等效"重力"变为 (mg + F)：

支持力 N = (mg + F)cosθ → 增大（A 对）
摩擦力 f = μN = tanθ·(mg+F)cosθ = (mg+F)sinθ → 增大（D 对）
沿斜面合力：(mg+F)sinθ − f = 0 → 仍匀速（B 对）

题目选错误的，"物体将沿斜面加速下滑"（C）错误。选 C。

例14 · 斜面平抛 D
题型：斜面平抛的水平位移范围

落到斜面上时，位移偏角 = 斜面倾角 θ：

tanθ = y/x = (½gt²)/(v₀t) = gt/(2v₀)
→ t = 2v₀tanθ/g
→ 水平位移 x = v₀t = 2v₀²tanθ/g ∝ v₀²

都落到斜面上：x₁ : x₂ = v₀² : (2v₀)² = 1 : 4

都落到水平面上：下落高度相同 → 时间 t 相同，x ∝ v₀ → 比值 1 : 2

所以实际比值在 1:2 ~ 1:4 之间（含端点）。1:5 超出范围，不可能。选 D。

例15 · 皮带传动比例（多选） ABC
方法：列表法解传动问题

半径：r_A = 3r，r_B = r，r_C = 2r。

第一步：A、B 同轴 → ω 相同，设 ω_A = ω_B = ω₁：

v_A = ω₁·3r ， v_B = ω₁·r → v_A : v_B = 3 : 1

第二步：B、C 皮带传动 → v 相同：

v_C = v_B = ω₁·r
ω_C = v_C / (2r) = ω₁/2

线速度之比 v_A : v_B : v_C = 3 : 1 : 1 → B 正确

角速度之比 ω_A : ω_B : ω_C = ω₁ : ω₁ : ω₁/2 = 2 : 2 : 1 → C 正确

向心加速度 a = v·ω：

a_A = 3ω₁r · ω₁ = 3ω₁²r
a_B = ω₁r · ω₁ = ω₁²r
a_C = ω₁r · ω₁/2 = ½ω₁²r

a_A : a_B : a_C = 3 : 1 : 0.5 = 6 : 2 : 1 → A 正确，D 错误。
