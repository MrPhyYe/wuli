机车启动模型：速度 v、牵引力 F、功率 P、加速度 a 对应关系表

共同基本关系（任何时刻都成立）： $$P = F\,v, \qquad F - f = m\,a$$ 其中 $f$ 为阻力（恒定），$m$ 为机车质量，$P$ 为实际功率，$P_{\text{额}}$ 为额定功率。

模型一：以恒定功率启动（$P = P_{\text{额}}$ 从一开始就满功率）

启动瞬间即以额定功率运行，速度从小到大逐渐增加，直到最大速度后匀速。

物理量 表达式 变化趋势（随时间 $t$） 说明 / 临界点
功率 $P$ $P = P_{\text{额}}$ 不变（恒定） 从 $t=0$ 起就达到额定功率，发动机"油门踩到底"。
速度 $v$ $v = \dfrac{P_{\text{额}}}{F}$ 逐渐增大，最后趋于 $v_m$ 不能突变：$t=0$ 时 $v=0$，此时牵引力 $F$ 极大（理论上）。
牵引力 $F$ $F = \dfrac{P_{\text{额}}}{v}$ 随 $v$ 增大而减小 $v$ 越大，$F$ 越小；当 $F = f$ 时加速度为零。
加速度 $a$ $a = \dfrac{F - f}{m} = \dfrac{1}{m}\!\left(\dfrac{P_{\text{额}}}{v} - f\right)$ 随 $v$ 增大而减小（变加速） $a$ 与 $v$ 成反比关系，速度越大加速度越小。
最大速度 $v_m$ $v_m = \dfrac{P_{\text{额}}}{f}$ —（最终达到） 当 $F = f$，$a=0$，速度不再增加，此后机车做匀速直线运动。
运动性质： $t=0 \to$ 变加速直线运动（$a$ 逐渐减小）$\to$ $F=f$ 时 $\to$ 匀速直线运动（速度 $v_m$）。
$v-t$ 图：斜率（即 $a$）逐渐变小，曲线向上凸，最后变成一条水平线。

模型二：以恒定加速度启动（先匀加速，后变加速，最后匀速）

启动阶段保持牵引力恒定、加速度恒定，做匀加速直线运动；当功率增大到额定功率后，功率不能再升，进入第二阶段。

阶段一：匀加速阶段（$a = a_0$ 不变）

物理量表达式变化规律
加速度 $a$$a = a_0$人为设定的恒定加速度，保持不变。
牵引力 $F$$F = f + m\,a_0$由牛顿第二定律，$F$ 必须恒定，才能保持 $a$ 恒定。
速度 $v$$v = a_0 t$随时间线性增大。
实际功率 $P$$P = F\,v = (f+m a_0)\,a_0 t$随时间线性增大，直到 $P = P_{\text{额}}$ 为止。
阶段一结束时
速度 $v_1$		 $v_1 = \dfrac{P_{\text{额}}}{F} = \dfrac{P_{\text{额}}}{f + m\,a_0}$ 此时功率达到额定功率，匀加速阶段结束。
阶段一持续时间
$t_1$		 $t_1 = \dfrac{v_1}{a_0} = \dfrac{P_{\text{额}}}{a_0(f + m\,a_0)}$ 匀加速一共能维持多长时间。

阶段二：变加速阶段（$P = P_{\text{额}}$ 恒定）

物理量表达式变化规律
功率 $P$$P = P_{\text{额}}$已经到顶，不能再增大。
速度 $v$从 $v_1$ 继续增大到 $v_m$仍然在加速，但加速度越来越小。
牵引力 $F$$F = \dfrac{P_{\text{额}}}{v}$$v$ 增大 $\Rightarrow$ $F$ 减小。
加速度 $a$$a = \dfrac{F-f}{m} = \dfrac{1}{m}\!\left(\dfrac{P_{\text{额}}}{v} - f\right)$$F$ 减小 $\Rightarrow$ $a$ 减小。

阶段三：匀速阶段

物理量表达式说明
牵引力 $F$$F = f$牵引力等于阻力，合力为零。
加速度 $a$$a = 0$速度不再变化。
最大速度 $v_m$ $v_m = \dfrac{P_{\text{额}}}{f}$ 与模型一最终速度相同，因为只取决于额定功率和阻力。

两种启动方式核心对比

对比项 模型一：恒定功率启动 模型二：恒定加速度启动
启动瞬间功率直接达到 $P_{\text{额}}$从零开始逐渐增大到 $P_{\text{额}}$
启动瞬间加速度很大（$F$ 极大）由人为设定，较小且恒定
牵引力变化从大一直减小到 $f$先恒定，再减小到 $f$
功率变化始终 $P_{\text{额}}$先增大，再保持 $P_{\text{额}}$
速度图象 $v$-$t$曲线斜率逐渐减小（上凸曲线）先直线上升，再接一段上凸曲线，最后水平
最终最大速度$v_m = \dfrac{P_{\text{额}}}{f}$（两种方式完全相同）
易错点提醒：
  • 机车不能同时做到"功率已经是额定功率"又"加速度还保持原来那么大"。功率到顶后，速度再想增大，只能以牺牲加速度为代价。
  • $v_1 = \dfrac{P_{\text{额}}}{f + m a_0}$ 是匀加速阶段结束的速度，不是最大速度；最大速度是 $v_m = \dfrac{P_{\text{额}}}{f}$，且 $v_1 < v_m$。
  • 当题目说"机车以恒定功率启动"，就走模型一；说"机车以恒定加速度启动"，就走模型二。
